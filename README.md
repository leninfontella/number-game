
# Number Game

![Number Game](public/og-image.png)

Um jogo simples de adivinhação de números. Descubra o número correto usando as dicas fornecidas a cada tentativa.

## Tecnologias

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Vite

## Como executar

```bash
npm install
npm run dev
```

Depois, acesse [http://localhost:8080](http://localhost:8080).

## Produção

```bash
npm run build
npm run preview
```
